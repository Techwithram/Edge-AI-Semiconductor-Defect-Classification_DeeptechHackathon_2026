# Model Evaluation Results

The trained Edge-AI defect detection model was evaluated on a validation dataset using standard object detection metrics.

## 📊Performance Metrics

| Metric | Value |
|------|------|
| mAP@50 | 0.9288 |
| mAP@50–95 | 0.7483 |
| Precision | 0.9081 |
| Recall | 0.8963 |

## 🔍Interpretation

- **High mAP@50** indicates strong defect detection capability
- **Balanced precision and recall** suggest reliable defect identification
- **mAP@50–95** reflects realistic localization performance under stricter criteria

These results demonstrate the suitability of the model for real-time semiconductor inspection under edge-compute constraints.
